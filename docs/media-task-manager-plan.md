# 媒体任务管理器实施方案

## 1. 定位

客户端采用 Motrix 的任务管理体验，但只服务于媒体解析和下载。客户端本地完成平台解析、浏览器登录态读取、yt-dlp/FFmpeg 调用、任务调度和文件保存，不依赖远程 Worker。

## 2. 功能范围

### 首期支持

- 单个媒体 URL 解析；
- 小红书、抖音、B 站用户主页批量解析；
- 用户主页作品列表；
- 视频、音频、图文分组展示；
- 本地浏览器登录态读取；
- 应用内浏览器会话；
- yt-dlp、HTTP 和 FFmpeg 下载；
- 任务暂停、恢复、取消、重试；
- 封面、进度、速度、剩余时间和错误日志；
- 本地设置、历史记录和任务恢复。

### 暂不支持

BT、磁力、Tracker、UPnP/NAT-PMP、FTP、插件市场、Headless Server、浏览器扩展和 Motrix MDXP 协议。

## 3. 页面结构

```text
应用窗口
├── 左侧导航
│   ├── 全部任务
│   ├── 下载中
│   ├── 已完成
│   └── 设置
├── 顶部工具栏
│   ├── 新建任务
│   ├── 粘贴链接
│   ├── 开始全部 / 暂停全部
│   ├── 搜索
│   ├── 筛选和排序
│   └── 列表 / 卡片视图
└── 任务列表
    └── 任务详情抽屉
```

任务列表每项显示封面、标题、平台、媒体类型、状态、进度、大小、速度、剩余时间和操作菜单。点击任务后打开右侧详情抽屉。

## 4. 解析和入队流程

```text
输入 URL
  ↓
识别单个媒体或用户主页
  ↓
读取浏览器登录态
  ↓
普通解析；必要时用应用内浏览器会话
  ↓
显示封面和媒体结果
  ↓
选择媒体类型、质量和保存目录
  ↓
创建任务并进入队列
```

主页任务在加入队列前只读取用户主页的作品列表，并提供视频、音频、图文过滤。图文结果只显示图片数量和保存方式，不显示视频画质。

## 5. 任务状态

```text
parsing → queued → downloading → completed
                         ├──────→ paused → queued
                         ├──────→ failed → queued
                         └──────→ cancelled
```

任务需要保存来源 URL、平台、标题、封面、媒体类型、解析方式、目标文件、保存路径、进度、速度、错误信息和创建时间。应用重启后恢复未完成任务，并根据状态决定继续、暂停或等待用户重试。

## 6. 任务详情

- **概览**：标题、平台、来源地址、解析方式、创建时间；
- **媒体文件**：视频、音频、图片文件和文件状态；
- **下载进度**：大小、速度、剩余时间、重试次数；
- **活动日志**：解析阶段、浏览器连接、网络请求和下载器输出；
- **错误信息**：可读错误、重试按钮和解决建议。

日志不能包含 Cookie 值、Authorization、签名参数或完整敏感请求头。

## 7. 设置

### 常规

默认保存目录、启动时恢复任务、完成通知、关闭窗口时最小化到托盘。

### 文件

文件名模板、同名文件处理、按平台或用户创建子目录、图文图片目录结构。

### 下载

最大并发数、全局速度限制、单任务速度限制、连接超时、重试次数和失败任务自动重试。

### 媒体

默认视频质量、默认音频格式、音视频合并方式、封面保存策略和字幕策略。

### 浏览器

自动选择浏览器、登录态读取状态、应用内浏览器会话状态、已保存的浏览器 Profile。

### 工具

yt-dlp 和 FFmpeg 路径、版本检查、更新状态和诊断信息。

### 外观

深色模式、列表密度、封面大小、语言和列表/卡片默认视图。

## 8. 分层设计

```text
Renderer
  └── typed IPC
Main Process
  ├── MediaResolver       解析 URL、主页和媒体信息
  ├── BrowserSession      浏览器 Cookie 和应用内浏览器会话
  ├── DownloadExecutor    yt-dlp、HTTP、FFmpeg
  ├── TaskQueue           调度、暂停、恢复、重试
  ├── TaskStore           设置、历史和任务持久化
  └── NotificationService 托盘和系统通知
```

Renderer 不直接访问文件系统、Cookie、浏览器数据库或子进程。所有敏感操作由主进程完成，Renderer 只接收脱敏后的任务状态和日志。

## 9. 实施阶段

### 阶段一：Motrix 风格任务壳

完成左侧导航、顶部工具栏、任务列表、状态筛选和搜索。

### 阶段二：统一任务模型

将单条解析和主页批量解析统一转换为任务，接入现有本地下载队列。

### 阶段三：任务控制和详情

实现暂停、恢复、取消、重试、详情抽屉、文件列表和脱敏日志。

### 阶段四：下载设置

加入保存目录、并发、速度、重试、命名、媒体格式、浏览器和工具设置。

### 阶段五：桌面体验

加入任务恢复、系统通知、托盘、打开文件夹和应用更新状态。

## 10. 验收标准

- 用户能从一个媒体 URL 创建并完成下载任务；
- 用户能从主页作品列表勾选内容并批量入队；
- 视频、音频和图文显示各自适合的选项；
- 任务支持暂停、恢复、失败重试和应用重启恢复；
- 任务列表能按状态、平台、媒体类型筛选并搜索；
- 详情抽屉能解释解析和下载失败原因；
- 浏览器登录态和敏感请求信息不会进入 Renderer 或远程服务；
- 设置项修改后会影响后续任务，并在重启后保留。

## 11. 当前实现（2026-09-28）

本次实现位于 `electron-client/`，界面组件基于 shadcn/ui（Base UI）；设置与解析结果按需加载。

- 侧栏仅保留全部任务、下载中、已完成，默认进入全部任务；设置入口单独保留。等待、暂停、失败、取消的任务可在全部任务中查看和操作。
- 任务列表和封面卡片可切换，支持关键词、平台、媒体类型过滤及排序。
- 主界面直接显示任务列表，移除宣传区域及顶部统计卡片。
- 新建任务沿用封面解析结果，支持全选、Shift 连选、只看视频/图片、入队前修改默认目录。单次「下载所选」受单次批量上限约束（默认 20，0 为不限）。
- 解析结果每项可右键：单独下载视频/音频/封面、复制链接/标题/封面地址、保存封面、打开原网页；视频和音频条目可在应用内弹窗预览源网页（见下）。
- 解析成功的链接记入解析历史，可再次解析、搜索、删除或清空；可在设置中关闭记录。
- 主页与列表解析覆盖：抖音主页/合集/短剧、B 站主页/合集/分P、YouTube 频道与播放列表、Instagram、微博、微信公众号、X。小红书只支持单篇笔记，主页链接会直接提示不支持。
- 平台拒绝访问时区分需要登录、需要会员、需要购买、内容加密四种情况；只有前三种提供打开登录窗口。
- 详情抽屉提供概览、已保存文件、最近 150 条脱敏活动日志、单任务限速。概览显示已下载/总大小、速度、剩余时间和自动续传次数；失败时在顶部按错误类型给出说明和建议（需要登录/会员/购买/加密、地址失效、网络、磁盘空间、写入权限、合并转换），并就地提供重试，可登录解决的提供打开登录窗口（打开任务自己的页面）。文件页逐个检查文件是否仍在磁盘上并显示大小。
- 任务记录保存封面、媒体类型、文件大小和完成时间。主页任务绑定具体作品地址，下载时重新解析作品，并保存其中全部图片。
- 一次入队为一个批次，批次可整体暂停、恢复、重试、取消、删除；删除任务时可选择同时把文件移入回收站。
- 设置分为常规、下载、文件与媒体、浏览器、外观、工具与更新。
- 下载设置实际传递给 HTTP 下载器及本地 yt-dlp，包括限速、超时、重试；音频默认保持平台原格式，也可转换为 MP3/M4A/FLAC。
- 字幕可关闭、嵌入或另存文件，可指定语言并选择是否包含自动生成字幕；封面可另存文件、嵌入视频、嵌入音频（默认只嵌入音频），可转为 JPG。
- 文件名可选标题、日期和任务编号组合，可按平台建目录；合集与分P 默认保存到以合集名命名的子目录。任务编号避免覆盖，暂停/重试沿用原目标路径。
- 支持可选启动恢复、系统完成通知、关闭窗口隐藏到托盘；通过托盘菜单退出。
- 主进程日志按模块写入 `userData/logs/main.log`，凭据脱敏；详细日志开关记录每个请求，诊断导出附带最近日志。
- 直接读取浏览器登录态与应用内浏览器会话都留在本地；移除了主页喜欢、收藏参数。

### 预览

解析结果中的视频和音频条目可点播放按钮或右键「预览」，在窗口中间的弹窗里打开条目的源网页，使用应用内浏览器会话的登录态。平台网页禁止被 iframe 嵌入，因此网页是主进程叠加在主窗口上的 `WebContentsView`，渲染进程上报弹窗网页区域的位置，窗口缩放时同步。点击弹窗外、Esc（网页内按下也由主进程捕获，全屏时除外）或关闭按钮结束预览，视图移除并加载 `about:blank` 以停止播放。网页内全屏时视图铺满窗口，退出后回到弹窗。B 站分P 打开对应的 `?p=N`；网页在新标签打开的链接留在预览内。

### 行为边界

- `parsing` 是解析流程状态；持久化队列使用 `queued / running / paused / completed / failed / cancelled`，其中 `running` 对应界面的“下载中”。
- 全局限速采用保守的并发槽位均分。例如全局 1024 KiB/s、并发 2 时，每任务最多 512 KiB/s。空槽位不会将额度借给其他任务。修改全局限速或并发时，运行任务会重新排队并按新参数继续。
- 单任务限速和命名、格式、字幕、封面默认值在入队时保存；单任务限速可暂停后在详情调整。超时和重试设置在任务下一次执行时读取。
- 重试分两层：文件请求及媒体分片按重试次数设置自动重试；整个任务中断后再自动续传两次（20 秒、60 秒后），没有开关。平台拒绝访问（登录、会员、购买、加密）不自动续传，用户处理后手动重试。
- 续传取决于上游 Range/校验标识或 yt-dlp 能力；不支持续传或媒体地址变化时可能重新下载。
- 同名文件不覆盖：文件名带任务编号，不提供覆盖/跳过/改名策略设置。图文图片按 `-1..n` 后缀保存在同一目录。
- 图片保持原始格式；视频音轨自动选择并合并为 mp4（不兼容时 mkv），不提供音轨手选或合并格式设置。
- 工具路径由安装包管理，工具检测和版本展示已接入，工具随应用更新；当前不提供自定义二进制路径。
- 浏览器登录态自动选择本机浏览器 Profile（优先 Chrome），设置中只显示当前选择，不能手动切换。
- 界面文字只有中文；`locale` 设置目前只影响请求的 Accept-Language 和默认字幕语言。
- 预览弹窗里是完整网页，可能出现评论、推荐和登录提示；预览打开时，落在网页区域上的提示和菜单会被网页遮住。
- 持久化继续使用原子替换的本地 JSON，没有引入 SQLite。默认重启将中断任务置为暂停；开启启动恢复时只恢复原来运行或排队的任务。
- 通知、托盘和 Chrome 授权仍受操作系统及浏览器实际支持情况影响。

### 未完成

- 小红书主页批量解析：接口需要 `x-s` 签名，适配器未完成、未注册。
- 界面多语言：词典已有，界面未接入，暂不计划。
- 设置：封面大小、按作者建子目录、音视频合并格式、同名文件策略、失败任务自动续传开关、手动选择浏览器 Profile。
- 解析结果只看视频/图片，音频未单独筛选。

### 验证方式

使用既有 Vitest 与 Playwright Electron runner。领域验证覆盖批量暂停/恢复、主页作品绑定和多图下载、持久化恢复、HTTP 续传与限速、Cookie 域隔离。窗口验证通过真实本地视频、yt-dlp 和 FFmpeg 完成解析下载，比较落盘文件，并检查详情日志、筛选、视图、设置及重启持久化。

这些离线用例不替代抖音、小红书、B 站在真实登录态下的在线验证。
