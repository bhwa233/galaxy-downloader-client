# 0.7.4 · 设置精简与默认命令行

## 优化与修复

- 简化设置分类，将外观并入常规，将剪辑输出与转录配置合并为剪辑与字幕。低频配置直接展示，通过分组标题区分，说明文字改为简短提示。
- 更新区域只保留 yt-dlp 内核与客户端两行版本及检查更新入口，移除重复版本、FFmpeg 详情和检测工具。检查、下载及失败时继续显示对应反馈与进度。
- 语言、主题、下载目录等设置统一在保存后生效；切换分类保留草稿，无修改或输入不合法时禁用保存。字幕语言、订阅周期等选项跟随对应开关显示。
- 首次启动直接进入新建任务，沿用原格式、仅标题命名和按需下载模型等默认配置。
- 安装版默认后台配置 galaxy 命令和本机控制通道，支持失败重试，关闭后重启保持关闭；Windows 使用当前用户 PATH，macOS 与 Linux 使用带标记的用户 shell 配置。

- Simplify settings categories by merging appearance into General and combining editing output with transcription. Show less frequently used settings directly in labeled groups, with shorter help text.
