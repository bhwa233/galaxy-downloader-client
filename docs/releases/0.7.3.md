# 0.7.3 · 更新反馈与下载进度优化

## 优化与修复

- 设置中增加独立的应用更新卡片。检查更新立即显示加载动画，网络响应较慢时给出提示，超时后可重新检查，避免界面看起来卡住。
- 更新包下载显示百分比、已下载量、总大小、下载速度和预计剩余时间，并区分连接、下载、校验与安装就绪阶段；支持取消下载及失败后重试。
- 视频任务列表与详情统一下载进度展示。未知大小时显示已下载量和速度，传输停顿时清除过期速度与预计时间，暂停时停止进度动画。
- 调整进度条的高度和过渡动画，并适配系统的减少动画偏好。
- 移除常规与订阅设置中的系统通知测试区域及对应测试命令，保留正常的下载完成和订阅通知。
