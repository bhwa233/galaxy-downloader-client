# 0.9.0 · 移除剪辑模式

## 变更

- 移除工作模式开关，客户端只保留下载模式。视频处理工作台、本地转写与说话人分析、软字幕、硬字幕、双语字幕合成、视频转码和改分辨率不再由下载器提供，字幕与视频处理由独立的 Galaxy Clipper 客户端承接。
- 下载相关的选项全部集中到 设置 → 文件与媒体：保存封面、把封面嵌进视频或音频、封面格式、写入元数据、保留章节、仅音频的格式（原始音轨 / MP3 / M4A / FLAC），以及把平台字幕另存为 SRT 文件。
- 嵌入封面、元数据和音频转换直接作用于下载的文件，不再额外保留 `.edited` 副本。
- 「仅音频下载时嵌入封面」默认开启，现在在所有下载中生效。
- 容器不支持嵌入封面时（例如 MKV）跳过封面并在任务详情中提示，媒体照常保存，不再让整个任务失败。
- 安装包不再包含本地识别运行时和中文字幕字体，体积更小。

## 升级说明

- 旧设置中剪辑模式的字段在启动时丢弃；旧任务的字幕设置折算为「另存字幕文件」或「不下载」，未完成的旧剪辑任务继续时只下载、不加工。
- 应用数据目录下的 `processing` 文件夹（已下载的识别模型与转写记录）不会自动删除，不再需要时可手动删除。

## English summary

- Remove the work-mode switch; the client is a downloader only. The video-processing workspace, local transcription and speaker analysis, soft and burned-in subtitles, bilingual subtitle composition, transcoding and resizing move to the independent Galaxy Clipper client.
- Download options now live together under Settings → Files & media: save the cover, embed it in video or audio, cover format, embed metadata, keep chapters, audio-only format (original / MP3 / M4A / FLAC), and save platform subtitles as SRT files.
- Covers, metadata and audio conversion are applied to the downloaded file directly; no `.edited` copy is kept.
- "Embed the cover in audio-only downloads" is on by default and now applies to every download.
- When a container cannot take a cover (MKV, for example), the cover is skipped with a notice in the task detail and the media is still saved.
- The installer no longer ships the local recognition runtime or the CJK subtitle font.
- Old editing-mode settings are dropped on start; the `processing` folder in the app data directory is not deleted automatically.
