# 0.7.2 · 多平台解析提速

## 优化与修复

- B 站视频、分 P 和合集优先复用应用内会话，通过接口读取列表与可用画质，减少网页加载、页面等待和重复启动解析引擎。接口不可用时保留原有回退路径。
- 抖音复用页面签名环境和作品详情中已有的可播放画质，减少切换作品、主页和合集时的重复加载与画质采样。
- YouTube 频道列表和微信合集优先通过已有会话读取首屏及后续分页；微博在已有校验令牌时优先直接请求列表。
- X 和 Instagram 短期缓存动态查询与公开账号信息，减少分页时的重复读取；查询失效或登录会话变化后重新获取。
- 各平台下载任务短时复用已成功解析的单条作品，减少下载前的重复解析；微信公众号文章直接读取页面媒体，省去不必要的引擎尝试。
- 取消解析、切换作品、清除会话和退出时终止后台画质采样，减少无效请求和子进程等待。
