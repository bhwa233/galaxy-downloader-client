# 0.7.0 · 作者订阅与更新通知

## 新增

- 文件命名支持作者 ID、发布日期与自定义模板，提供实时预览；新任务不强制附加随机编号，重名自动编号，暂停及重启恢复保留名称。
- 合集支持原顺序、倒序及按发布时间排序，可查找整个列表的关键词、日期范围、媒体类型和时长，显示查找进度并支持停止与继续；B 站分页合集可直接倒序加载。
- 支持订阅 B 站 UP 主、抖音作者和 YouTube 频道，监听视频、图文及 Shorts 等平台支持的作品类型。
- 新增「订阅」页面，提供「更新」和「管理订阅」，支持按视频主、平台、关键词及未读状态筛选，并可批量标记已读。
- 所有已启用作者按统一周期依次检查，默认每 24 小时一轮，可在设置中调整间隔或关闭自动检查。顶部统一显示上次整轮检查时间、下一轮时间、检查进度与成功／失败数量。
- 新作品通过原生系统通知提醒，同一作者一次发现的多个作品合并通知；点击通知可恢复应用窗口并定位对应作者的未读更新。
- 设置页新增系统通知状态与「发送测试通知」，便于确认本机通知是否可用。

## 优化与修复

- 日期快捷项先高亮并填入起止日期，点击「应用并查找」后才生效；取消、关闭和清除草稿不会意外提交。
- 平台字幕及相关语言设置归入剪辑模式，下载模式的新任务只保存媒体；旧任务继续使用其保存的文件名和参数。
- 首次添加订阅只记录已有作品，后续按作品 ID 识别新增内容；订阅、已读状态及未完成轮次保存在本机，重启后继续，减少重复检查和提醒。
- 支持分批补查、暂停／恢复订阅以及登录／验证状态提示；部分作者检查失败时保留历史记录，并在整轮结果中单独统计。
- 作者主页和作品的主要操作统一进入应用内解析与画质选择，外部网页通过独立按钮打开；解析操作不会直接加入下载队列。
- 订阅列表复用任务列表布局，作者头像使用正方形比例，补齐 B 站及抖音头像，并明确显示「最近作品」摘要。
- 改进单实例启动与窗口恢复：提前获取实例锁，重复打开时恢复已有窗口，避免重复初始化服务或迁移数据。
