# 0.7.1 · 文件命名与登录体验优化

## 优化与修复

- 移除自动读取系统 Chrome、Edge、Firefox 登录态的功能及相关设置，统一复用应用内浏览器会话，减少登录态解密失败带来的重复等待。
- 文件命名默认改为「仅标题」，支持「标题 + 作者名」「标题 + 作者名 + 发布日期」及自定义，预设使用作者名称并将标题放在最前面。
- 长标题会为作者名和发布日期预留空间，缺少名称或日期时省略对应内容。旧的作者 ID 预设自动切换为「仅标题」，已入队任务继续使用保存的文件名。
- 链接输入框随长链接和分享文案自动增高，缩短或清空后自动缩回；窄窗口下正常换行，避免内容撑出窗口。
- 「订阅」移出「工作空间」，作为侧栏独立模块，保留未读数量、折叠导航及悬停提示。
- 合集排序精简为「合集原顺序」「合集倒序」，移除「最新发布」「最早发布」，继续支持按发布时间区间查找。
- yt-dlp 自动检查频率改为每周一次，保留手动检查、自动更新开关与版本回退。手动检查后重新计算下次检查时间，检查过程中关闭自动更新后不再安排后续检查。
- 普通解析失败时提供前往内核更新的入口，登录或访问验证问题继续显示对应的处理入口。

<summary>English summary</summary>

- Remove automatic sign-in extraction from system Chrome, Edge and Firefox profiles. Reuse the in-app browser session for parsing and downloads, avoiding failed system-cookie decryption and retries.
- Default to title-only filenames, with title + author name, title + author name + publication date, and custom alternatives. Presets use creator names and put the title first.
- Reserve space for author names and publication dates when titles are long. Omit unavailable fields, migrate older author-ID preferences to title-only, and preserve filenames for queued tasks.
- Let the link input grow with long URLs and shared text, shrink when content is shortened or cleared, and wrap within narrow windows.
- Move Subscriptions into its own sidebar group, retaining unread counts, collapsed navigation and tooltips.
- Keep collection order and reverse collection order, remove publication-time sorting, and retain publication-date range searches.
- Check for stable yt-dlp updates weekly. Keep manual checks, the automatic-update switch and rollback; reset the schedule after manual checks and honor disabling automatic updates during an active check.
- Offer a shortcut to kernel updates after ordinary parsing failures, while keeping dedicated sign-in and access-verification actions.
