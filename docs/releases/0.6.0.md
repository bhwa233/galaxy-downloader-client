# 0.6.0 · 合集解析与筛选体验升级

## 新增

- 支持按视频时长筛选：提供「1 分钟以内」「1–10 分钟」「10 分钟以上」和自定义区间，可与关键词、发布时间等条件组合使用，筛选结果同时作用于显示和全选。
- 哔哩哔哩视频属于合集时，分别展示「单视频」和「合集」，默认选中当前粘贴的视频，方便直接下载。
- 合集中标记「原视频」，并在标签上显示当前视频的位置，例如 `59/72`。

## 优化

- 利用哔哩哔哩视频接口返回的合集信息读取条目，减少额外分页请求；超过解析上限时给出截断提示。
- 长列表随滚动分批显示卡片，改善长合集的初始显示和前段滚动体验，全选和下载仍按筛选后的完整列表处理。
- 统一「单视频 / 多P / 合集」等标签文案，将标签与筛选、视图操作放在同一行，减少重复标题。
- 「只看视频 / 图文」仅在当前列表同时包含相关类型时显示。

## 修复

- 修复粘贴合集内视频后，默认选中合集第一条、可能下载到其他视频的问题。
- 修复平台首页、信息流等不支持的链接被误报为「需要登录」的问题，改为提示使用具体作品、合集或作者主页链接。
- 修正多标签结果的解析历史数量，避免被「单视频」标签的一条记录影响。

## 使用提示

- 平台没有提供时长的条目，在开启时长筛选后会被排除。
- 长列表采用分批显示，滚动到后部后卡片仍会累积，滚动性能可能继续受到列表大小影响。
