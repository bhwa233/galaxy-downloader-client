# 0.8.0 · 下载职责收敛与处理稳定性

## 优化与修复

- 将智能选片、草稿、封面和云端剪辑入口从下载器移除，相关能力由独立的 Galaxy Clipper 客户端承接。
- 修复本地转写的 VAD 分段恢复逻辑，静音间隔不会被重新加入识别队列；旧版本分块缓存会自动失效并重新建立。
- 退出客户端时等待下载、转写和媒体处理任务完成清理，避免子进程或临时文件残留。
- 检测到原始媒体缺失或签名变化时停止继续读取，保留已有处理记录。
- 打包产物排除 Electron 运行时调试日志。

## English summary

- Remove smart clipping, drafts, covers and cloud clipping entry points from the downloader; these capabilities now live in the independent Galaxy Clipper client.
- Fix local transcription recovery so VAD silence gaps are not sent back to recognition; invalidate chunk manifests created by the older pipeline.
- Wait for download, transcription and media-processing cleanup during shutdown to avoid child-process or temporary-file leftovers.
- Stop reading source media when it is missing or has changed, while preserving existing processing records.
- Exclude Electron runtime debug logs from packaged artifacts.
